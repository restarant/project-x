## Project Overview

A modern, cloud-based restaurant POS system targeting small to medium cafés and restaurants. Unlike subscription-heavy competitors, this offers a complete café management package with a one-time pricing model.

### Competitive Advantage

- **Complete package**: POS + Website + QR Ordering + Kitchen Dashboard
- **One-time pricing** vs recurring subscriptions
- **AI-powered sales insights** (Phase 3)
- **Real-time digital menu updates**
- **WhatsApp integration** for orders and bills
- **No-app QR ordering** — customers scan & order from browser
